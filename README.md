# SlotMachine
Little SlotMachine game in C# with 3 working methods

# How to play?
- Go to https://sharpy-0zp2.onrender.com/ and paste the C# code written in CSlotMachine.cs
- Click "Compile"
- When it finished compiling, simply click the AvviaSlotMachine() method and type in the amount of money you want to bet
- If you have no money left, you can click in the Work() method, but be careful, not everything goes as expected!
- If you want to see how much money is left in your pockets, click the method Visualizza().

/ Have fun!
